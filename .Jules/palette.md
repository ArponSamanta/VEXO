## 2025-01-18 - Prevent Nesting Interactive Elements in Product Cards
**Learning:** Nesting interactive buttons (like "Add to Cart" or "Wishlist") inside parent React Router Link or anchor elements violates HTML/ARIA semantics, causes keyboard-navigation traps, and breaks screen reader narration. Additionally, hiding overlay quick-actions purely behind CSS hover triggers makes them completely inaccessible to keyboard-only users.
**Action:** Extract nested buttons out of Link/anchor tags into a shared relative-positioned parent container. Reveal visual quick-action overlays using Tailwind's `group-focus-within` selectors to match hover transitions for keyboard tab navigation, and always assign dynamic, screen-reader-friendly `aria-label` attributes to quick-action buttons.
