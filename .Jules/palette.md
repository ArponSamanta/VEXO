## 2026-07-30 - Accessible Interactive Product Cards
**Learning:** Nesting interactive components (such as action `<button>`s inside a React Router `<Link>`) creates severe keyboard traps and breaks accessibility validation. Additionally, hiding product quick-actions completely behind hover without `:focus-within` prevents keyboard users from ever accessing or knowing those action buttons exist.
**Action:** Always separate global navigation links from internal action buttons within card components. Set the image link to `tabIndex={-1}` to keep focus order clean and prevent duplicate routes, trigger quick actions visual transition on `group-focus-within` as well as hover, and style distinct action focus outlines using `focus-visible:ring-offset-2 focus-visible:ring-offset-vexo-bg`.
