## 2026-08-14 - Interactive Card Overlays Keyboard Accessibility
**Learning:** Nesting interactive elements (like custom action buttons) inside link anchors (like product card links) violates semantic HTML standards, resulting in erratic screen reader behavior and keyboard focus traps. Furthermore, hide-on-hover overlays block keyboard tab indexing entirely unless they are also shown via focus.
**Action:** Always isolate interactive buttons from link anchors in card lists. Use a shared relative parent container with the `group` class. Apply `group-focus-within:opacity-100 group-focus-within:translate-y-0` to slide-up overlays so they automatically display when focused via keyboard navigation. Use `tabIndex={-1}` on redundant image links when heading titles already navigate to the same route, avoiding duplicate tab stops.
