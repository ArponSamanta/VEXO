## 2025-02-13 - [Eliminating Nested Interactive Elements in Product Cards]
**Learning:** Nesting interactive `<button>` elements (such as quick-add-to-cart or wishlist buttons) inside a parent `<a>` or React Router `<Link>` violates HTML standards and results in broken accessibility, confusing screen reader readouts, and severe keyboard traps. Additionally, any interactive buttons that are hidden by default on hover must also support `group-focus-within` styles so keyboard navigators can reveal and focus them seamlessly.
**Action:** When designing hover-trigger quick actions inside product or grid cards, separate the main image link and the quick action buttons as siblings rather than children. Set `tabIndex={-1}` and `aria-hidden="true"` on the redundant image link if the title link already leads to the same path, and apply Tailwind's `group-focus-within:opacity-100` alongside high-contrast focus rings for flawless focus states.
