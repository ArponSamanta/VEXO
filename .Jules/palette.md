## 2026-03-02 - [Semantic HTML & Keyboard-Accessible Hover Disclosures]
**Learning:** Nesting interactive buttons inside an anchor link component (such as React Router's `<Link>`) is invalid HTML. It corrupts screen reader tab sequences and makes nested buttons entirely unreachable via standard keyboard navigation. Additionally, hiding disclosure controls with `opacity-0` on hover blocks keyboard tab accessibility unless Tailwind's `group-focus-within:opacity-100` and `group-focus-within:translate-y-0` are applied to reveal the actions container automatically when any child button receives focus.
**Action:** Decouple nested interactive elements from within anchor/link components by grouping them as sibling elements inside a relative parent wrapper. Apply `group-focus-within` on hovered action containers, add explicit `focus-visible:ring-2` focus states, and use the robust `role="img"` rating accessibility pattern for star rating wrappers.
