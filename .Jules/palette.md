## 2026-07-28 - Keyboard Hover and Redundant Focus Mitigation in Grid Card Layouts
**Learning:** In responsive grids where interactive product cards have quick actions and redundant links (like both the product image and title pointing to the same product detail page), keyboard navigability can quickly become cluttered. Keyboard focus flow can be kept clean by using `tabIndex={-1}` on the product image Link component, while relying on Tailwind's `group-focus-within` triggers to reveal hovered actions on keyboard focus.
**Action:** Set `tabIndex={-1}` on decorative or redundant image-only wrapper links. Utilize `group-focus-within:opacity-100` and `group-focus-within:translate-y-0` on container transitions to ensure seamless visibility for screen-reader/keyboard-only users.
