## 2025-02-15 - Product Card Keyboard Accessibility
**Learning:** When elements are hidden by default via hover-triggered opacity transformations (e.g., product quick actions), they remain inaccessible to keyboard users because focusing elements inside does not automatically trigger the hover state. Applying Tailwind's `group-focus-within:opacity-100` and `group-focus-within:translate-y-0` on the hidden container ensures it becomes visible when any of its interactive child elements receive focus.
**Action:** Always combine hover-based visibility classes with `group-focus-within` equivalents when container elements hold interactive children. Additionally, set `tabIndex={-1}` on redundant adjacent links (like image links when a title link also exists) to streamline the keyboard tabbing path.
