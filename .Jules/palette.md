## 2026-05-18 - Accessible Interactive Elements in Card Grids
**Learning:** In e-commerce card patterns, placing interactive action buttons (like "Add to Cart" or "Wishlist") inside an image's `<Link>` or `<a>` tag creates invalid nested interactive elements that trap keyboard navigation and confuse assistive technologies. Furthermore, hover-only quick actions remain inaccessible to keyboard users unless explicitly paired with Tailwind's `group-focus-within:opacity-100` and `group-focus-within:translate-y-0`.
**Action:** Always wrap card media and action buttons in a non-interactive container `div`, decouple action buttons from anchor links, silence redundant card image links with `tabIndex={-1}` and `aria-hidden="true"` (relying on the titled link for navigation), and ensure action overlays reveal gracefully via `:focus-within`.
