## 2026-03-01 - Accessible and Focusable Product Grid Cards
**Learning:** Nesting interactive components (such as buttons) inside other interactive components (like anchor links/React Router Links) violates HTML/ARIA validation, breaks keyboard tab ordering, and results in unpredictable focus behavior. Overlaying quick action buttons that only show on hover means keyboard-only users will miss them unless their parent container leverages tailwind utilities like `group-focus-within` to gracefully reveal them when receiving focus. Additionally, to avoid redundant screen reader noise and clean up tab stops in grids, the secondary image-only links should have `tabIndex={-1}`, and star rating SVGs should be wrapped in an elements group with `role="img"` and a combined descriptive `aria-label`, leaving individual SVGs with `aria-hidden="true"`.
**Action:** When designing hover-based quick-action controls on grid cards, always wrap the base interactive element cleanly, avoid nested interactive tags, use `pointer-events-none` on overlay badges, provide screen-reader-friendly labels containing the specific entity's name (e.g., product name), and make sure everything is reachable and visible via standard keyboard tabbing by using `group-focus-within`.
